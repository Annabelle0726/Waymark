# Waymark repository instructions

Follow the [root project instructions](agent.md), including the language requirements for the Chinese README and other Markdown files.

Before any UI or styling change, you MUST read and follow [the UI rules](src/styles/agent.md). After the change, complete the pre-commit checklist at the end of that file.

Registration and sign-in MUST require a phone number. Follow the [account identity rules](agent.md#account-identity) for password authentication, number validation and honest SMS verification status. Email MUST NOT replace the required phone number.
